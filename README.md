# henrytran07.github.io

Portfolio site. Static frontend plus a FastAPI backend (`loc ai` chatbot) that runs as a single
Vercel serverless function.

## Layout

```
api/index.py        Vercel entrypoint — puts the repo root on sys.path and exposes `app`
app/main.py         FastAPI app: page routes, static mounts, CORS
app/chat.py         /api/chat router (Groq)
app/schemas.py      request models
templates/          Jinja sources for the home and cv pages
index.html          generated by build_static.py (GitHub Pages)
cv/index.html       generated by build_static.py (GitHub Pages)
static/ scripts/ data/ cv_doc/    assets served straight from the CDN
vercel.json         routing + function config
build_static.py     renders templates/ into index.html and cv/index.html
```

## Local development

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
echo "GROQ_API_KEY=your_key_here" > .env
uvicorn app.main:app --reload --port 8000
```

Open http://localhost:8000 and http://localhost:8000/cv.

## Deploying to Vercel

1. Push to GitHub.
2. In the Vercel project: Settings → Environment Variables → add `GROQ_API_KEY` for
   Production, Preview and Development. The `.env` file is gitignored and never deployed.
3. Redeploy. Check `https://<your-deployment>/api/health` — it returns the model id and
   `key_loaded: true` when the environment variable is wired up.

## Regenerating the GitHub Pages copy

`templates/` is the single source of truth. After editing a template:

```bash
python build_static.py
```

This rewrites `index.html` and `cv/index.html`. On `github.io` the chatbot automatically
calls `https://henrytran07-github-io.vercel.app/api/chat`; everywhere else it calls the
current origin. To override, set the `api-base` meta tag value in `build_static.py`.
